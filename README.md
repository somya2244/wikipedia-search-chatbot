# Wikipedia Search Chatbot

A beginner-friendly Python chatbot that uses the Wikipedia library to search topics, display summaries and provide Wikipedia page links.

## Features
- Random greeting messages
- Wikipedia search results
- Wikipedia summaries
- Page title and URL retrieval
- Error handling for ambiguous and unavailable pages

## Technologies Used
- Python
- Wikipedia Python library

## Installation

Install the required library:

```bash
pip install wikipedia
```

## Run the Project

```bash
python Wikibot.py
```
